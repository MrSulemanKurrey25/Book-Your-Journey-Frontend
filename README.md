#  ✈️ Book Your Journey | Frontend Project
A sleek, responsive travel booking platform designed to make exploring the world effortless.

# ✨ Key Features
Destinations: Interactive gallery of 12 global tourist spots.

Responsive: Fully optimized for mobile, tablet, and desktop.

# 🛠️ Tech Stack
HTML / CSS: Modern layouts with Flexbox and Grid.

JavaScript: Dynamic content rendering and event handling.

Google Fonts & FontAwesome: High-quality typography and icons.
